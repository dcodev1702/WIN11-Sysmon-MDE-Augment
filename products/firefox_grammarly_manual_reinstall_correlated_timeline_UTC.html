02 · Policy semantics

Block by default, allow Grammarly by exception

The policy is one JSON object stored as one REG_MULTI_SZ element. A specific add-on ID overrides the wildcard default.

{"*":{"installation_mode":"blocked","blocked_install_message":"Only approved extensions may be installed."},"87677a2c52b84ad3a151a4a72f5bd3c4@jetpack":{"installation_mode":"allowed"}}
Wildcard default

"*" = blocked

Every extension without a more-specific add-on ID is blocked. The wildcard establishes default-deny behavior rather than naming one blocked extension.

User-facing message

Only approved extensions may be installed.

blocked_install_message explains the administrative decision when Firefox denies an unapproved installation.

Specific override

Grammarly = allowed

The exact Firefox add-on ID at the end overrides "*". The user may install Grammarly normally from AMO.

Allowed is user-driven

installation_mode: allowed does not install the XPI by itself. The user initiates installation, and the extension remains removable. No install_url is required for this AMO workflow.

Force installed is mandatory

installation_mode: force_installed automatically installs from a configured install_url and prevents normal user disable/removal. That is deliberately not the policy used here.

10 · Permissions

Grammarly access model: TVM KB summary plus Firefox manifest

The TVM knowledge-base table currently returns Grammarly enrichment for Chrome and Edge. Because this is the same Grammarly product family, those risk labels are summarized for Firefox and checked against the signed Firefox XPI manifest.

High-impact scope

All HTTP and HTTPS pages

The Firefox manifest requires http://*/* and https://*/*. Its content script also matches <all_urls>. TVM KB rates the broad host scope High.

Browser context

Tabs, cookies, and identity

The manifest requires tabs, cookies, and identity. TVM KB describes tabs as URL/favicon access and cookies/identity as Medium-to-High impact context.

Optional escalation

Clipboard and native messaging

clipboardRead and nativeMessaging are optional, not baseline required permissions. TVM KB rates them Medium and High respectively.
